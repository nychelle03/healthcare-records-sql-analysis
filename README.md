## 🌷 Project Overview

This project uses a fictional healthcare records request dataset to explore how SQL can help analyze operational performance.

The goal is to identify request volume trends, processing delays, employee workloads, and opportunities to improve records release workflows.

## 🎯 Project Objectives

- Analyze healthcare records request volumes
- Calculate processing turnaround times
- Compare request types and facility workloads
- Identify processing bottlenecks
- Practice beginner and intermediate SQL queries
- Communicate findings and recommendations

## 🛠️ Tools & Skills

**Tools:** SQLite, DB Browser for SQLite, GitHub

**SQL Skills:** SELECT, WHERE, ORDER BY, GROUP BY, HAVING, JOIN, CASE WHEN, subqueries, CTEs, and window functions

## 📊 Analysis Questions

1. How many records requests are received?
2. Which facilities submit the most requests?
3. What is the average processing turnaround time?
4. Which request types take the longest to complete?
5. Which employees process the highest number of requests?
6. What patterns may indicate workflow bottlenecks?
